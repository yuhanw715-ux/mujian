MUJIAN / 暮笺

把暮笺装进 iPhone

Windows 10 → GitHub 构建 → 下载 IPA → 自己签名安装

这次使用一个全新的仓库，例如 mujian。

不用 Mac，不用安装 Xcode。你原来的待办项目 miu-memo 继续保留。这个包是源码，IPA 会由 GitHub 构建生成。

已经安装过暮笺？

不用再建仓库，请先阅读 1.1.1 更新步骤。下面是第一次安装的流程。

1 · 下载并解压

把 Mujian-Source.zip 完整解压到一个新文件夹，例如 D:\Mujian-Source。进入里面的 Mujian，应看到 App、scripts、project.yml、README.md。

Windows 可能隐藏 .github 文件夹，但请不要删掉它，构建步骤就在里面。

2 · 新建 GitHub 仓库

  1. 登录 GitHub，点右上角 ＋ → New repository。
  2. 名称填 mujian；可选 Private。
  3. 不勾选 README、.gitignore 和 License，让它保持空仓库。
  4. 创建后复制 HTTPS 仓库地址，例如 https://github.com/yuhanw715-ux/mujian.git。

3 · 上传源码

在能看到 project.yml 的文件夹中右键 → Git Bash Here。只执行下面这一行：

bash scripts/publish-github.sh

提示粘贴仓库地址时，输入第 2 步复制的地址，按回车。如果询问 Git 提交名称或邮箱，填写你的提交身份；它不是登录密码，不会修改全局 Git 配置。

Git 可能唤起浏览器登录，也可能直接复用你之前的登录。如果最后看到 Upload complete，就已上传。create mode ... 只表示本地提交，还要等推送完成。

不要把多行命令粘成一行。如果出现 ^[[200~，按 Ctrl+C 清空，再手动输入上面这一行。不需要输入开头的 $。

4 · 在 GitHub 开始构建

  1. 刷新新仓库页面，确认能看到源码。
  2. 进入 Actions。
  3. 若 GitHub 要求启用工作流，选择启用。
  4. 左侧点 Build iOS IPA。
  5. 点 Run workflow，分支选 main，再点绿色 Run workflow。
  6. 进入刚出现的任务，等待它结束。Queued 表示排队，黄色表示还没结束，绿色 Success 表示构建成功。

首次安装构建工具可能会久一点。工作流仅手动运行，等待时不必反复点 Run workflow。

5 · 下载 IPA

  1. 进入那次绿色任务的 Summary。
  2. 向下找到 Artifacts。
  3. 点 Mujian-IPA 下载 ZIP。
  4. 解压 ZIP，里面有 Mujian-unsigned.ipa 和校验文件 SHA256.txt。
  5. 把 .ipa 文件交给你之前使用成功的签名工具，再安装到 iPhone。

不要把 GitHub 下载的外层 ZIP 当作 IPA，也不要继续解压 IPA 本身。unsigned 表示尚未签名。

6 · 第一次打开

先用一两篇虚构文字试试保存、重开、导入和备份恢复。文件名缺少完整日期时会要求选择日期；同一天支持多篇，两种作者都可以写或导入。

遇到问题，看这里

没有 Build iOS IPA：确认仓库根目录能看到 project.yml 和 .github/workflows/build-ios.yml，不是把整个 Mujian 文件夹套在仓库的下一层。

Git 没弹浏览器：如果推送已成功，通常是复用了登录，不必重新登录。若有红色报错，保留完整错误再处理。若再次出现 failed to load library 'libcurl-4.dll'，需要修复 Git for Windows 安装，不是暮笺代码问题。

Actions 变红：展开红色步骤，找最早出现的 error:。也可以在 Summary 下载 Mujian-build-log 发给 Miu。单独的 exit code 65 是结果，不是具体原因。

TXT 乱码：导入预览里的“文件编码”换成 UTF-8、UTF-16 LE 或 GB18030 / GBK，确认文字正确后再保存。Miu 不需要看你的日记正文。

IPA 安装失败：先记录签名工具的错误。构建成功只能确认生成了 App；证书、签名有效期和安装结果仍取决于你用的签名工具。不要为重试安装而卸载一个还没备份的 App。

之后升级：先导出备份；签名工具尽量沿用同一应用标识和签名身份。覆盖安装能否保留数据以工具实际行为为准。

日记只保存在本机，App 不联网同步。导出的备份包含日记、草稿和图片；它是可读文件，请自己保管好。卸载 App 会失去其本地数据，换机和卸载前都要先导出备份。
