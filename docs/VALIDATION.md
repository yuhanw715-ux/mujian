## 针对四个问题的改动

1. 月历和单日页面成对移除 `matchedTransitionSource` / `navigationTransition(.zoom)`，改用系统普通导航转场，避免透明日期格子的放大 / 收回快照形成白块。日记卡片到阅读页的缩放仍保留。
2. TXT 使用 `UIDocumentPickerViewController` 的复制导入模式；允许文件提供商返回通用数据类型，再验证 `.txt`。后台在安全作用域内协调读取，并限制实际读取字节数。选择器完全关闭后才切换到预览；读取进度、取消与失败均有反馈。
3. 将“正在浏览的月份”与“明确要求跳转的月份”分开；每次今天 / 日期选择生成独立请求，直接居中，避免同值赋值无效和双向反馈。布局变化与跳转任务可取消，旧任务不会覆盖较新的请求。
4. 移除月历双指张开、单日双指收拢及相应说明；保留点按日期、点空白返回、左上角返回。装饰图片编辑的缩放不受影响。

这些是基于源码和用户截图的针对性修复；没有声称已在 iPhone 上复现并验证消除所有症状。

## 仍需要 GitHub / 手机验证

当前环境没有 Xcode、iOS SDK 或 iPhone 模拟器，**未完成 iOS 类型检查、链接、模拟器或真机运行**。语法解析与核心测试不等于完整 iOS 编译通过。GitHub 工作流会在 macOS 再运行核心测试（额外检查 Apple 平台的 GB18030），并执行完整 arm64 编译。

建议安装后使用虚构内容试一次：

1. 浅色 + 自定义背景下，连续点开不同日期，再点空白 / 返回按钮；暗色也试一次，观察日期格子是否还出现白块。
2. 点 + → 导入 TXT，从“我的 iPhone”选 `Tests/Fixtures/2026-10-09_Miu_Test.txt`，确认出现预览、识别日期和 Miu 作者，点确认收藏后出现在对应日期。
3. 导入 `Choose_Date_Test.txt`，必须选择日期后才能收藏；取消选择文件不应新增日记。错误文件应显示原因。
4. 分别试已下载的 iCloud / 第三方云盘 TXT；文件选择器负责下载，文件交给 App 后显示读取状态。慢读取期间取消，再次导入不应被上一份结果覆盖。
5. 滑到远月份、把本月稍微滑偏、快速翻月后、从“日记”页，分别点“今天”；连续点击也应回本月并居中。横竖屏切换应保留完整月份。
6. 双指在月历上张开、在单日收拢均不再导航；日期点击和空白返回仍有效。日记卡片、按钮的点击不应误触空白返回。
7. 先从旧 App 导出完整备份，再覆盖更新；确认原日记、草稿、图片和主题仍在。应用标识继续为 `app.miu.mujian`，覆盖安装是否保留数据取决于签名工具和签名身份。

排错只需构建错误或不含私密内容的界面截图，不需要发送日记正文。
