- 两种写作标记与正文、身份、草稿、备份一起往返；编辑保留标记，旧备份不覆盖较新的标记；拒绝未知的字段取值。

原有 101 项日期、文本编码、备份迁移、图片 / 主题、TXT 文件读取、导入关闭顺序、取消回调和“今天”定位检查继续通过。

## 界面改动检查

- 日记栏按日期归组，展示双方总数与各日篇数，可筛选“篇数不同”。点击日期组后进入单日，再选择日记全文。
- Miu 在日记栏、单日卡片、TXT 导入预览和草稿列表不显示正文；回收站使用通用标题。单日卡片以序号区分同一天的多篇 Miu 日记。
- 新日记栏使用透明 ScrollView，沿用 HomeView 的同一个 CalendarBackdrop；图片、图层、主题和暗夜猫爪共同生效。
- 月历标签纵向排列：Miu 在上，小暮暮在下；特别紧凑时显示颜色点，并给辅助朗读完整的作者 / 标记说明。
- 颜色同时配合文字和符号：暮紫 / 当日写下、青色 / 后来补写、灰色 / 未标记、粉色 / Miu。
- 编辑、导入时选择写作标记；已有条目从全文的“…”菜单也可修改，不额外新增日记。修改标记同步关联草稿，避免草稿覆盖新标记。
- 新的日期卡片在窄屏上下排列、宽屏并排；更大辅助字号采用纵向布局。开启键盘时折叠写作标记选择区，给正文保留空间。

## 必须由 GitHub / 手机确认的范围

当前环境没有 Xcode、iOS SDK 或 iPhone 模拟器。**没有在这里完成 iOS 类型检查、链接、原生 UI 渲染或真机运行**。语法与核心检查不等于完整 iOS 构建通过。GitHub 会在 macOS 再跑核心检查（多验证两项 GB18030），随后执行完整 iPhone arm64 构建。

安装后建议使用虚构文字确认：

1. 写一篇小暮暮日记，分别选择当日 / 补写；导入 TXT 时也试一次。退出重开后标记应保留。
2. 升级前的日记应仍在，默认未标记；点全文的“…”修改标签，正文、日期和原有篇数不变。
3. 导入一篇 Miu 测试日记，确认导入预览、日记栏、单日卡片均不露出正文；从单日点卡片后显示完整正文，返回后再次收起。
4. 在日记栏搜索 Miu 测试正文中的独有词，应不产生匹配；按日期 / 作者仍可找到；VoiceOver 不应读出隐藏标题或正文。
5. 月历与日记栏比较图片背景、图层、明暗主题；检查窄屏 / 横屏及大字号，标签不得互相覆盖。
6. 在同一天放入不同数量的双方日记，切换“篇数不同”；回收站的日记不应计入总数。
7. 用新版导出并恢复备份，检查两种标记、旧日记、草稿、图片和主题；导入旧版备份应可用。新版备份需要 1.2 或更新版读取。
8. 再试上一版已修复的今天定位、TXT 选择和返回转场；月历双指导航应继续关闭。

应用标识仍是 `app.miu.mujian`。先导出完整备份，再使用原签名方式覆盖更新；不需要提供真实日记来排错。
