- 使用 Swift 官方 Linux 工具链 6.0.3，按 Swift 5 语言模式编译 `App/Core/*.swift` 和 `Tests/CoreTests.swift`，运行结果为 **71 项检查通过**。

## 手机上建议先试一次

1. 用虚构文字写一篇“我写的”，保存后关闭、重开 App，确认文字仍在。
2. 导入一个带日期的虚构 TXT，确认出现在相应日期；再导入一个无日期文件，确认必须选择日期。
3. 在同一天添加第三篇，确认能全部打开。
4. 分别更换单日背景和月历背景，确认互不覆盖；旋转屏幕确认卡片重排及月份重新居中。
5. 写一份草稿，点“稍后再写”，到草稿箱继续；编辑已存在的日记时，原文在正式收藏前保留。
6. 导出完整备份，恢复同一备份，确认没有产生重复日记。
7. 将一篇测试日记移到回收站，再恢复，确认它回到原日期。
8. 在 1.0 先备份，再覆盖升级到 1.1，检查已有日记 / 草稿 / 单日背景。
9. 上下轻滑、快速滑动和突然停手，观察吸附是否自然、当前月日期是否完整、邻月是否更淡；检查二月、五行月份和六行月份。
10. 在不同日期附近双指张开，松手进入该日；没达到阈值时恢复原状。打开日记卡片、点按钮不应触发空白返回；空白和双指收拢可返回。
11. 上传两张透明 PNG，拖动到重叠位置，先后点击两张图片的“置顶”，检查覆盖顺序；退出重开、导出恢复后顺序应保留。
12. 分别选择白昼、暗夜、跟随系统；检查日期文字和玻璃底栏对比度。开启减弱动态效果时猫爪应静止，关闭猫爪开关应消失。

本次实现采用 SwiftUI 的原生滚动和缩放导航：双指松手达到阈值后进入单日，并非复刻系统日历内部逐级变形的全部细节。真实触控、取消手势、吸附阻尼和玻璃材质的效果尚需真机验证。

这些步骤仅用虚构内容即可。排错只需构建错误或不含私密内容的界面截图，不需要发送日记正文。
